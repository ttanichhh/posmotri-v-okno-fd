# Посмотри в окно

Учебный проект Яндекс Практикума: страница для поиска и просмотра видео из разных городов с фильтрацией по времени суток.

Используются HTML, CSS и JavaScript. Вёрстка выполнена по макету с использованием Flexbox.

Для запуска откройте `index.html` через Live Server.

Репозиторий: https://github.com/ttanichhh/posmotri-v-okno-fd
